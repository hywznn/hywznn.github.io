문제 해결
01

같은 요청을 왜 두 번 판단해야 할까?

PLAN과 ANALYZE에서 동일한 요청을 다시 분류했습니다. 단계마다 Intent가 달라지면 서로 다른 Workflow를 선택할 수 있었습니다.

제가 바꾼 부분

PLAN에서 결정한 Intent·Workflow를 저장하고 ANALYZE에서 재사용하도록 Server–AI 계약을 개선했습니다.

변경 전PLAN 분류 → ANALYZE 재분류
변경 후PLAN 분류·저장 → ANALYZE 재사용
2 → 1동일 요청의 Intent 분류 횟수

중복 분류를 제거하고, 단계 간 Workflow 선택을 일관되게 유지했습니다.

02

서류를 받았는데, 업무는 멈춰 있었습니다.

근로자가 문서를 제출해 OCR이 끝나도 이후 업무로 이어지지 않았습니다. 문서 처리와 업무 상태 갱신 사이의 연결이 필요했습니다.

제가 바꾼 부분

Outbox와 멱등 OCR 접수, HR 검토·승인 결과 반영을 연결했습니다. 최신 Context로 업무를 재개하도록 처리했습니다.

변경 전문서 제출 → OCR → 흐름 단절
변경 후OCR → HR 검토 → 업무 재개 → 초안
OCR → 재개끊긴 비동기 업무의 연결

승인된 문서 정보를 반영해 Workflow를 재개하고 문서 초안 생성까지 연결했습니다.
